◆ manageIncomingTcpMessage()

quint64 TicTacToeLANClientMdiSubWindow::manageIncomingTcpMessage ( QTcpSocket * socket)
private

Manage all incoming messages from server.

Parameters
socketSocket needed for replying to server.
Returns
A bit-to-bit result, where each bit has this meaning:
  • [0] = get-player-info message managed.
  • [1] = game-ready message managed correctly.
  • [2] = set-turn message managed correctly.
  • [3] = token-inserted message managed correctly.
