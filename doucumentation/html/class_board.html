Insert a new token given in token on the board, given the grid position in position.

Parameters
positionThe position where you want to insert the token.
tokenThe token that you want to insert.
Returns
A status code that represents the result of this function:
  • [0] → The token is inserted correctly.
  • [1] → The cell is busy with the same token given in token.
  • [2] → The cell is busy with a different token given in token.
