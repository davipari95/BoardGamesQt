qint8 TicTacToeLanClientSettingsMdiSubWindow::checkLineEdits ( QHostAddress & out_hostAddress,
quint16 & out_port,
QString & out_username ) const
private

Check the validity of input fields for the server connection.

This function check if input fields (ipAddressLineEdit, portLineEdit and usernameLineEdit) on user interface (IP, port and username) contains valid values. If a value is not valid, the corrisponding bit will be set to 1.

  • [0] → IP address is not valid.
  • [1] → Port is not valid.
  • [2] → Username is not valid.
Parameters
[out]out_hostAddressA validated IP address.
[out]out_portA validated port.
[out]out_usernameA validated username.
Returns
3 bits value that indicates which fields are not valid (0 if all fields are valid).
