◆ setPosition()

qint32 GridPosition::setPosition ( const qint32 & row,
const qint32 & column )

Set a new position given the row in row and the column in column.

If the row is different from the previous one, the signal rowValueChangedSignal() will be emitted. If the column is different from the previous one, the signal columnValueChangedSignal() will be emitted.

Parameters
rowThe value of the row that you want to set.
columnThe value of the column that you want to set.
Returns
A bitwise status as following:
  • [0] → The row is different from the previous one.
  • [1] → The column is different from the previous one.
