◆ manageInsertToken()

bool TicTacToeLanServerMdiSubWindow::manageInsertToken ( QTcpSocket * client,
QStringList & args )
private

Manage the command insert-token and reply to client.

The client will receive one of the following answer:

  • OK → The cell is free and a token will be inserted.
  • BUSY → The cell is busy by another token.
  • NYT → Is not the turn of the client.
Parameters
clientClient that had sent the message. Server will responds here.
argsArguments containing the token informations (token, row and column).
Returns
Returns true if the commands is correctly managed, false otherwise.
